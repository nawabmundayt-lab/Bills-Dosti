# 💻 billsplit-dost — Next.js PWA

Phase 3 scaffold of **BillSplit Dost** (see [../ROADMAP.md](../ROADMAP.md)).

- **Stack:** Next.js 15 (App Router) · TypeScript · Tailwind v4 · Serwist PWA · next-intl (en/ur/hi) · Firebase (lazy, demo mode) · Zustand · React Query
- **Docs:** `../docs/phase-03/01-setup-notes.md` · design system `../docs/phase-02/`

```bash
npm install
npm run dev        # → http://localhost:3000 (redirects to /en)
npm run build      # prod + service worker
```
