# 🏗️ Bills-Dosti — BillSplit Dost

A bill-splitting PWA for **Pakistan 🇵🇰 & India 🇮🇳** — Next.js 15 + Firebase, wrapped for Play Store via TWA. Track the hisaab, settle via Raast/JazzCash/Easypaisa/UPI deep links — money never touches our servers.
